💰 Calculate Shipping Cost

POST /api/bts/calculate

Calculate shipping cost between two cities using BTS logistics service.

Request Headers

Authorization: Bearer YOUR_API_TOKEN
Content-Type: application/json

Request Body

{
    "senderCityId": 6,
    "receiverCityId": 8,
    "weight": 2.5,
    "volume": 0.1,
    "senderDate": "2024-01-20",
    "senderDelivery": 1,
    "receiverDelivery": 1
}

Parameters

  • senderCityId (integer, required): BTS city ID for sender
  • receiverCityId (integer, required): BTS city ID for receiver
  • weight (number, required): Package weight in kg (must be > 0)
  • volume (number, optional): Package volume in cubic meters
  • senderDate (string, optional): Send date in Y-m-d format (min: tomorrow, max: +30 days)
  • senderDelivery (integer, required): 0 = pickup, 1 = door-to-door
  • receiverDelivery (integer, required): 0 = pickup, 1 = door-to-door

Success Response (200)

{
    "data": {
        "summaryPrice": 92000,
        "currency": "UZS",
        "requestData": {
            "senderCityId": 6,
            "receiverCityId": 8,
            "weight": 2.5,
            "volume": 0.1,
            "senderDate": "2024-01-20",
            "senderDelivery": 1,
            "receiverDelivery": 1
        },
        "senderCity": "г.Ташкент",
        "receiverCity": "г.Нукус"
    }
}

Error Response (422)

{
    "errors": {
        "weight": ["Вес должен быть больше 0"],
        "senderDate": ["Дата отправки должна быть минимум завтра: 2024-01-16"]
    }
}

🌍 Get Regions

GET /api/bts/regions

Get list of all available regions in Uzbekistan.

Query Parameters

  • language (string, optional): Response language - ru, uz, en (default: ru)

Request Example

GET /api/bts/regions?language=ru
Authorization: Bearer YOUR_API_TOKEN

Success Response (200)

🏙️ Get Cities

GET /api/bts/cities

Get list of cities, optionally filtered by region.

Query Parameters

  • regionId (integer, optional): Filter cities by region ID
  • language (string, optional): Response language - ru, uz, en (default: ru)

Request Examples

# Get all cities
GET /api/bts/cities
Authorization: Bearer YOUR_API_TOKEN

# Get cities in specific region
GET /api/bts/cities?regionId=6&language=ru
Authorization: Bearer YOUR_API_TOKEN

{

        {
            "id": 6,
            "name": "г.Ташкент",
            "name_ru": "г.Ташкент",
            "name_uz": "Тошкент шаҳар",

Get cities for a specific region. Perfect for dynamic dropdown loading when user selects a region.

❌ Error Codes

HTTP Status Codes

  • 200 - Success
  • 401 - Unauthorized (invalid or missing token)
  • 422 - Validation Error (invalid parameters)
  • 500 - Internal Server Error

Common Error Messages

# Missing authentication
{
    "name": "Unauthorized",
    "message": "Your request was made with invalid credentials.",
    "code": 0,
    "status": 401
}

# Validation errors
{
    "errors": {
        "weight": ["Вес должен быть больше 0"],
        "senderCityId": ["Неверный ID города отправителя"],
        "senderDate": ["Дата отправки должна быть минимум завтра: 2024-01-16"]
    }
}

# Server error
{
    "errors": {
        "general": ["Ошибка сервиса расчета доставки"]
    }
}

🔧 Integration Examples

JavaScript/AJAX Example

// Calculate shipping cost
fetch('/api/bts/calculate', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer ' + userToken
    },
    body: JSON.stringify({
        senderCityId: 6,        // Tashkent
        receiverCityId: 8,      // Nukus
        weight: 2.5,            // 2.5 kg
        senderDelivery: 1,      // Door-to-door
        receiverDelivery: 0,    // Pickup
        senderDate: '2024-01-20'
    })
})
.then(response => response.json())
.then(data => {
    if (data.data) {
        console.log('Shipping cost:', data.data.summaryPrice, 'UZS');
    } else {
        console.error('Errors:', data.errors);
    }
});

📝 Notes

  • All endpoints require authentication via Bearer token
  • Dates must be in Y-m-d format (YYYY-MM-DD)
  • Minimum send date is tomorrow, maximum is 30 days in future
  • Weight must be greater than 0
  • City and region IDs must be valid BTS identifiers
  • All prices are returned in UZS (Uzbek Som)
  • Language parameter accepts: ru, uz, en (default: ru)
